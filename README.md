# Lift App

Source for the Lift app deployed at https://am-lift.netlify.app/

Currently a single self-contained `index.html` that uses:
- [Chart.js](https://www.chartjs.org/) (via CDN)
- [Firebase](https://firebase.google.com/) (via CDN) — Firestore for data storage

## Deploying

This site is connected to Netlify. Pushing to the linked branch triggers a new deploy.
